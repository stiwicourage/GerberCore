The essentials

Everything you need.
Nothing you don't.

Gerber Core provides the shared experience and a curated collection of small developer utilities. Platform-specific workflows belong in plugins.

Interactive command palette

Discover commands, navigate nested menus, and stay in your flow without memorizing every command.

Developer utilities

Use small, platform-independent developer utilities directly in the terminal through /tools.

Secrets management

Manage credentials through a consistent /secrets interface backed by secure credential storage.

Plugin lifecycle

Discover, review and approve plugins. Decide which integrations become available in your Gerber session.

Cross-platform PowerShell

Built for PowerShell 7.4+ across macOS, Windows and Linux, without a separate terminal UI framework.

Extensible by design

Add new workflows through independent modules while keeping Gerber Core free of vendor-specific logic.

Integrate your stack

Your platforms.
Your choice.

DevOps integrations can be distributed as PowerShell module dependencies. Gerber asks before enabling their command namespaces, and plugins remain independent of Core.
